


Project: AI Travel Planning & Experience Engine (POC Stage)Objective: Build a zero-cost, zero-infrastructure functional prototype that aggregates location data, optimizes multi-day travel routes, and renders an interactive itinerary map.🏢 System Architecture & API Stack1. Core Data & POI LayerService: Overture Maps / Overpass API (OpenStreetMap)Feature Used: Geographic Entity RetrievalFunction: Pull raw data (names, category tags, lat/lng coordinates, opening hours) for cultural attractions, parks, and restaurants within a specific bounding box or radius of the target city.2. Geocoding & Search LayerService: Radar.io API (Alternative: Mapbox Search)Feature Used: Forward Geocoding & Autocomplete SearchFunction: Convert user-typed destinations (e.g., "New Delhi") into explicit coordinate anchors to seed the engine's location requests.3. Routing & Matrix LayerService: OpenRouteService (ORS) APIFeature Used: Time-Distance Matrix & Direction RoutingFunction: Calculate the pairwise travel durations/distances between all retrieved points of interest (POIs). Generate final polylines (path data) for the optimized itinerary.4. Contextual LayerService: Open-Meteo APIFeature Used: Weather Forecast & Historical Climate DataFunction: Fetch real-time forecasts to dynamically shift indoor/outdoor activities or use historical data to suggest optimal travel windows.5. Presentation LayerService: Leaflet (with CARTO dark basemap tiles)Feature Used: Interactive Map Rendering & Polyline DrawingFunction: Display a responsive interactive map showcasing daily travel pins, routes, and sequenced stop paths.⚙️ Primary Data Engine FlowIngest & Parse: Capture destination city $\rightarrow$ Geocode via Radar $\rightarrow$ Pull top 15 matching POIs via Overpass/Overture.Matrix Evaluation: Compute the cost matrix (walking or driving time) for the 15 POIs via OpenRouteService Matrix.Clustering & Sorting: Execute a greedy clustering algorithm to group nearby POIs into explicit day-by-day blocks based on geographical proximity and time constraints.Render: Output a structured JSON itinerary payload to the front-end interface, binding coordinate arrays to Leaflet for path visualization.
